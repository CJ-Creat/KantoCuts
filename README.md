## Project Description

KantoCuts is a PHP and MySQL barbershop management system. Customers can register, log in, and book services, barbers, and hairstyles through the web interface. Administrators manage live queues and update shop records using a dedicated dashboard with dark mode support.

**Problem it solves:** Replaces manual queue tracking and walk-in congestion with an online booking and live queue management system.

## Functionalities

- Add data (Create customer accounts, add queue entries, submit barber ratings)
- View data (Display available barbers, service pricing, hairstyle options, and real-time queue status)
- Update data (Change barber availability and progress queue status: Waiting → Ongoing → Done)
- Delete data (Cancel queue entries)
- API integration (Process user authentication, account creation, and admin login via JavaScript Fetch requests to `api.php` endpoints)
